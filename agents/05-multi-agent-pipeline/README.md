# 05 · Multi-agent Pipeline

An orchestrator agent that delegates to 2-3 specialized worker agents (e.g., a researcher, a writer, a fact-checker) and stitches their outputs together. The hard part isn't the orchestration — it's debugging which worker failed and why, when something goes wrong.

## What you'll learn

How LangWatch's nested span tree makes multi-agent debugging tractable, and how per-worker evaluators surface cascade failures that would be invisible to end-to-end metrics.
