# 03 · Tool-use Agent

An agent with multiple tools (calculator, web fetcher, code runner) that picks which one to call. The interesting part isn't the tools — it's measuring tool *selection accuracy* and parameter extraction quality with a golden dataset of queries labeled with the correct tool + correct args.

## What you'll learn

How to instrument function calling in LangWatch (every tool call as its own span with the args + result), and how a single tool-description rewrite can fix entire classes of wrong calls.
