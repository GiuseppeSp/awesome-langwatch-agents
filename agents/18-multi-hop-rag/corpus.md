# Corpus — a fictional academic registry

Each bullet states exactly ONE fact. No single passage contains a full chain, so
a question like "in which place does Aldric work?" cannot be answered from one
retrieval: you must first learn Aldric's academy, THEN where that academy stands.
Crucially, the answer-bearing passage shares no keyword with the original
question (the bridge entity — the academy — isn't in the question), so a single
keyword retrieval cannot reach it. That is what forces multi-hop.
