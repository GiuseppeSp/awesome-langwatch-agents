# 02 · Multi-turn Chatbot

A conversational agent that maintains context across turns — and measures how well it actually does that. Compares two memory strategies (sliding window vs LLM-summarized) on the same conversation set to show when each one wins.

## What you'll learn

How to instrument multi-turn conversations in LangWatch so the Thread tab shows full conversations grouped together, and how to measure context preservation with an evaluator that checks whether the agent's nth response is consistent with turns 1..n-1.
